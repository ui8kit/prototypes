# AGENTS

Wireframe constructor on top of `ui8kit/contract`. **Prototypes are rectangle-only**: every block, rendered as it is (feed, catalog, tests, any render without a mode), draws shapes only: no images, no words, no icons. Real content is the builder's page mode: the **same composition** with its places filled from data (`builder/BlockView mode="page"`), never a second version of a block. Copy `.cursor/rules` and `.cursor/skills` as-is. Details: rules `00`–`05`, `10-contract-package`, `ui8kit-primitives`.

## This repo

- **Layer:** prototypes (blocks) + a thin showcase app. No layouts package.
- **Runtime:** Svelte 5 only. The eight-runtime identity rule is a contract target, not generated here.
- **Kit:** `packages/kit/src` from `npx ui8kit@3 add --all` (Svelte, registry 3.4.0). Never hand-edit those files. `ui8kit.lock.json` pins sha256 of every installed path. Reinstall: `bun run kit:install` (`docs/kit.md`).
- **Blocks:** `packages/blocks`. The organisms are **generated**: `HeroSimple` (`hero-simple`, `hero@1`) and `TeamSimple` (`team-simple`, `team@1`) from codegen-x/ui8kit `packages/prototypes`, synced into `packages/blocks/src/generated` (svelte, contracts, models, manifest with sha256 per file) by `scripts/sync-codegen.ts` and pinned by `codegen.lock.json` (repo, commit, path, manifest sha256). **Never edit `src/generated` by hand**; change codegen-x and re-sync (`bun run sync:codegen -- --update <commit>`). `src/manifest/registry.ts` builds `BLOCKS` from the generated contracts (+ a category) and `MODELS` from the generated models; `src/catalog.ts` maps item → generated component. A builder saves `{ id, item, variant, options?, props }`. Hand-written: layout shells and shapes (theme panels), `classes.ts`, manifest helpers, `BlockView`, fixtures. Rules: `docs/content-contract.md`.
- **Utilities:** `packages/blocks/src/classes.ts` is the only home for raw Tailwind strings in the hand-written part. `scripts/check-blocks.py` fails a hand-written block `.svelte` file that embeds more than **0** utility tokens; it skips `src/generated` (checked byte for byte by `sync-codegen --check`, its rules run in codegen-x) and requires `blockRoot` = `src/generated/svelte/blocks` plus any hand-written organism dirs.
- **Modes:** `wireframe` is the default everywhere (the generated organisms take a `mode` prop, default `wireframe`): shapes only, no words, no links, no content images, no labelled landmark, 3 placeholder members. Only `builder/BlockView` passes `mode="page"` explicitly: the same composition draws the content with `data-place` / `data-field` on each place. Empty optional values render nothing.
- **Instance options:** `{ id, item, variant, options?, props }`; `options` are the contract `settings`: `level` 1–3 (default 2, list item titles one level below), `padding` (`compact` py-8 lg:py-16 | `standard` py-16 lg:py-32, default | `spacious` py-24 lg:py-40; the app passes the theme's section padding through `paddingOf()`, theme `default` = `standard`) and `landmarkLabel`. Checked by `validateInstance()`; `instanceProps()` / `wireframeProps()` build the organism props.
- **Shapes:** hand-written `TextLine`, `Heading`, `Badge`, `CtaShape`, `Media`, `Dot`, `Avatar`, `Surface` serve the theme panels (MiniPage, DesignPanel); the blocks use the generated shapes (`ShapeHeading`, `ShapeText`, `ShapeBadge`, `ShapeCta`, `MediaFramePlace`). Interactive kit widgets are **not** implemented in `packages/blocks`.
- **Binding:** `data-place` (place id) + `data-field` (space-separated concrete JSON pointers, `/members/1/title`), as `bind(manifest, place, index)` resolves them from the contract places. `data-slot` / `data-role` / `data-shape` are theme hooks only.
- **Field budget:** each content model is **5–10** paths. A list counts as one field; its item fields count too. `registry.node.test.ts` fails outside 5–10.
- **App:** `apps/blocks`: **Catalog** is one vertical feed of every registered block in every variant, full width, always rectangle-only (`wireframeProps`: no content). **Builder preview** (separate view, `?view=preview&sample=`) renders the saved sample instances (`filled` / `minimal` / `swapped`, `src/fixtures/samples.ts`, flat `hero@1` / `team@1`) through `BlockView mode="page"`. Plus a **Theme** button that opens the Theme sheet (kit `Dialog` docked right, as in `codegen-x/ui8kit` `apps/stock`). Light/dark is the standard `dark` class on `<html>` from the fixed bottom-right `ThemeToggle` (localStorage `ui8kit-theme`). Fonts are not part of the constructor.
- **Roles:** token + height per meaning (`docs/blocks.md` → Roles). Do not add a role without a row there and a case in `shapes/roles.test.ts`.
- **Theme:** `packages/theme`. Model and JSON config are codegen-x/ui8kit `magazine-theme` v2 (`theme.ts`, `design.ts`; fixtures + round-trip tests in `codegen-x.test.ts`); keep them compatible. Exact skin tokens (`skin-tokens.ts`, generated by `scripts/port-skins.mjs`); the app adds only the wireframe legibility floor. Per-element radius, density and shadow tokens: shapes keep plain classes + `data-slot` / `data-shape`, `packages/blocks/src/tokens.css` reads `--radius-*`, `--h-*` / `--w-*` / `--pad-card`, `--shadow-*`; never `--spacing`. Section padding is a real class pair on `Block` (`py-8 lg:py-16` / `py-16 lg:py-32` / `py-24 lg:py-40`, all multiples of 8px; ui8px layout spacing lists 32 and 40). Details: `docs/theme.md`.

## Contract gaps

- `@ui8kit/contract` Codex v0.4 / `codex:validate` is not wired here; it runs in codegen-x, where the models and organisms are generated. `packages/blocks/src/content/en.ts` holds only the app's interface text.
- `codegen-x/ui8kit` `packages/tooling` and `packages/ui-gates` are private and not copied. `check-blocks.py` is the local structural stand-in.
- Official `npx ui8kit@3` loads `@ui8kit/registry` from npm via CDN (unpkg → jsDelivr). Retry with `--retry` / `--registry-url`; do not copy primitives by hand (`docs/kit.md`).
- `ui8px` is a devDependency (`^0.2.5`). Run it via `bun` / `npx` (`scripts/ui8px.mjs`). Do not vendor it.

## Do not

- Edit `packages/kit/**` by hand.
- Put Tailwind class strings in hand-written organism `.svelte` files.
- Edit `packages/blocks/src/generated/**` by hand (re-sync from codegen-x instead).
- Add `rounded-lg` / `rounded-md` / `rounded-xl`, shadow utilities (`shadow-*`), gradients, or palette colors. Elevation is a theme token only (`shadow-card` / `shadow-media` → `tokens.css`).
- Put visible words in templates. `aria-label` and field labels come from `content/en.ts`; content comes from `props` (samples: `src/fixtures`).
- Look up places in the DOM to swap shapes for text (a second render path). Bind places directly in the organism.
- Import interactive kit widgets (`Dialog`, `Select`, `Disclosure`, …) into `packages/blocks`. Draw them as rectangles.
- Open a PR for constructor work: commits on `main` as **Grok Bot** `<grokbot@users.noreply.github.com>`.

## Add a block

See `docs/adding-a-block.md`. Short path: author the model, organism and block spec in codegen-x/ui8kit (`line: "simple"`) → push → `bun run sync:codegen -- --update <commit>` → register the contract in `BLOCKS`, the model in `MODELS`, the organism in `CATALOG` → fixtures → `bun run verify`.

Do not fork a block because the image moved or the column count changed. Do not hide a filled field in a variant. Do not add a schema per variant. Keep the model inside 5–10 fields.
