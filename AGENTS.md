# AGENTS

Wireframe constructor on top of `ui8kit/contract`. **Prototypes are rectangle-only**: every block, rendered as it is (feed, catalog, tests, any render without a mode), draws shapes only: no images, no words, no icons. Real content is the builder's page mode: the **same composition** with its places filled from data (`builder/BlockView mode="page"`), never a second version of a block. Copy `.cursor/rules` and `.cursor/skills` as-is. Details: rules `00`–`05`, `10-contract-package`, `ui8kit-primitives`.

## This repo

- **Layer:** prototypes (blocks) + a thin showcase app. No layouts package.
- **Runtime:** Svelte 5 only. The eight-runtime identity rule is a contract target, not generated here.
- **Kit:** `packages/kit/src` from `npx ui8kit@3 add --all` (Svelte, registry 3.4.0). Never hand-edit those files. `ui8kit.lock.json` pins sha256 of every installed path. Reinstall: `bun run kit:install` (`docs/kit.md`).
- **Blocks:** `packages/blocks`. Layout shells wrap kit `Box` because UI8Kit v3 has no `Block` / `Container` / `Stack` / `Grid` primitives. Semantic `tag`, `gap`, `align`, `justify`, `cols`, `py` live on those shells. Each organism has a sibling `*.block.ts` **manifest** (stable item id, category, content `model`, `places` = field → place binding by JSON pointer, layout-only `variants`). Content models live in `src/models` (`hero@1`, `team@1`; TS types, `validate()`, JSON Schema). A builder saves `{ id, item, variant, props }`. `src/manifest/registry.ts` is keyed by item id; `src/catalog.ts` maps item → component `{ variant, mode, content }`. Rules: `docs/content-contract.md`: simple content, interchangeable variants, full rendering, one composition for wireframe and page.
- **Utilities:** `packages/blocks/src/classes.ts` is the only home for raw Tailwind strings in the constructor. `scripts/check-blocks.py` fails a block `.svelte` file that embeds more than **0** utility tokens, and requires a matching `*.block.ts`.
- **Modes:** `wireframe` is the default everywhere and needs no prop; organisms have **no mode prop** and never read it. The mode is a context set only by `builder/BlockView` (`mode="page"` explicitly): the same places then draw kit `Text` (`h1`–`h4`/`p`/`span`), `Button` with `href` (= `<a>`), `Image` (`src`/`alt`, optional `srcDark`; `src` = `https://` URL or `/path`). Empty values render nothing; empty wrappers are dropped. The mode, `data-place` / `data-field` bindings and wireframe shapes live only in `src/places` and `src/shapes`; `check-blocks` rejects them in organisms.
- **Instance options:** `{ id, item, variant, options?, props }`; `options.headingLevel` 1–3 (default 2, same look; list item titles one level below). Declared in the manifest `options`, checked by `validateInstance()`.
- **Shapes:** `TextLine`, `Heading`, `Badge`, `CtaShape`, `Media`, `Dot`, `Avatar`, `Surface` (wireframe). **Places** (`src/places`): `BadgePlace`, `HeadingPlace`, `TextPlace`, `ActionPlace`, `MediaPlace`, `AvatarPlace`: one per kind of spot, wireframe shape or page element. Organisms import layout shells, `Surface` and places only. Accordion, tabs, carousel and other interactive kit widgets are **not** implemented. Kit controls in `packages/blocks`: `Text` in places, `Button` (link) only in `ActionPlace`; `Image` only in `Media` and `places/ThemedImage`.
- **Binding:** `data-place` (place id) + `data-field` (space-separated concrete JSON pointers, `/members/1/title`) from `bind(manifest, place, index)`. `data-slot` / `data-role` / `data-shape` are theme hooks only.
- **Field budget:** each content model is **5–10** paths. A list counts as one field; its item fields count too. Cardinality and wireframe bars do not multiply. Tests fail above 10 (and below 5). Counts: `docs/fields.md`.
- **App:** `apps/blocks`: **Catalog** is one vertical feed of every registered block in every variant, full width, always rectangle-only (no mode, no content). **Builder preview** (separate view, `?view=preview&sample=`) renders the saved sample instances (`filled` / `minimal` / `swapped`, `src/fixtures/samples.ts`) through `BlockView mode="page"`. Plus a **Theme** button that opens the Theme sheet (kit `Dialog` docked right, as in `codegen-x/ui8kit` `apps/stock`). Light/dark is the standard `dark` class on `<html>` from the fixed bottom-right `ThemeToggle` (localStorage `ui8kit-theme`). Fonts are not part of the constructor.
- **Roles:** token + height per meaning (`docs/blocks.md` → Roles). Do not add a role without a row there and a case in `shapes/roles.test.ts`.
- **Theme:** `packages/theme`. Model and JSON config are codegen-x/ui8kit `magazine-theme` v2 (`theme.ts`, `design.ts`; fixtures + round-trip tests in `codegen-x.test.ts`); keep them compatible. Exact skin tokens (`skin-tokens.ts`, generated by `scripts/port-skins.mjs`); the app adds only the wireframe legibility floor. Per-element radius, density and shadow tokens: shapes keep plain classes + `data-slot` / `data-shape`, `packages/blocks/src/tokens.css` reads `--radius-*`, `--h-*` / `--w-*` / `--pad-card`, `--shadow-*`; never `--spacing`. Section padding is a real class pair on `Block` (`py-8 lg:py-16` / `py-16 lg:py-32` / `py-24 lg:py-40`, all multiples of 8px; ui8px layout spacing lists 32 and 40). Details: `docs/theme.md`.

## Checks (zero baseline)

| --- | --- |
| `python3 scripts/check-blocks.py` | Block root, no nested/looped Block, no bare HTML, no literal copy, no inline style, forbidden radius/shadow/palette, max raw utilities = 0, sibling `*.block.ts`, `blockRoot` in sync, no interactive kit except `CtaShape` `Button` |
| `node scripts/ui8px-gate.mjs` | Extract class maps from `classes.ts`, `ui8px lint`, `validate grid`, `validate patterns`, `validate aria`. Gate `max: 0`, blocking `UI8PX001`, `UI8PX003`, `UI8PX005`, `GRID` |

| `vitest run` | Same filled object in every item × variant: text, href, src/alt, each member read from the DOM; cleared optional values leave no element / empty wrapper; wireframe of the same input is geometry only; pilot edits by pointer + variant switch + member swap; roles and tokens. `vitest.config.ts` pins `resolve.conditions: ["browser"]` |

Kit sources are not extracted: control recipes (`size-3`, `pr-2`) would trip layout 8+4.

## Contract gaps

- `@ui8kit/contract` Codex v0.4 / `codex:validate` is not wired. Dictionary keys live in `packages/blocks/src/content/en.ts`; content models are local (`src/models`) with generated JSON Schema, not Codex records.
- `codegen-x/ui8kit` `packages/tooling` and `packages/ui-gates` are private and not copied. `check-blocks.py` is the local structural stand-in.
- Official `npx ui8kit@3` loads `@ui8kit/registry` from npm via CDN (unpkg → jsDelivr). Retry with `--retry` / `--registry-url`; do not copy primitives by hand (`docs/kit.md`).
- `ui8px` is a devDependency (`^0.2.5`). Run it via `bun` / `npx` (`scripts/ui8px.mjs`). Do not vendor it.

## Do not

- Edit `packages/kit/**` by hand.
- Put Tailwind class strings in organism `.svelte` files.
- Add `rounded-lg` / `rounded-md` / `rounded-xl`, shadow utilities (`shadow-*`), gradients, or palette colors. Elevation is a theme token only (`shadow-card` / `shadow-media` → `tokens.css`).
- Put visible words in templates. `aria-label` and field labels come from `content/en.ts`; content comes from `props` (samples: `src/fixtures`).
- Look up places in the DOM to swap shapes for text (a second render path). Bind places directly in the organism.
- Import interactive kit widgets (`Dialog`, `Select`, `Disclosure`, …) into `packages/blocks`. Draw them as rectangles.
- Open a PR for constructor work: commits on `main` as **Grok Bot** `<grokbot@users.noreply.github.com>`.

## Add a block

See `docs/adding-a-block.md` and `docs/content-contract.md`. Short path: reuse or add a content model → dictionary → `*.block.ts` (model, places, layout variants) + registry + catalog → fixtures → organism of places bound with `bind()` → `bun run contract` → `bun run verify`.

Do not fork a block because the image moved or the column count changed. Do not hide a filled field in a variant. Do not add a schema per variant. Do not implement accordion/tabs/carousel as kit widgets. Keep the model inside 5–10 fields.
